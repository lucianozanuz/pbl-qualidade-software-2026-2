## Orientações para as evidências

1. Salvar as evidências da Atividade 1 em `docs/evidencias/atividade-01/`.
2. Utilizar nomes descritivos, sem espaços ou acentos.
3. Exemplo: `maria-pesquisa-localizacao-resultado.png`.
4. Referenciar cada arquivo no documento da atividade usando caminho relativo.
5. Uma imagem isolada não é suficiente. A resposta deve explicar o procedimento e o que a evidência demonstra.
6. Não incluir senhas, tokens, e-mails pessoais ou outros dados sensíveis.

## Declaração de responsabilidade

Os integrantes são responsáveis por verificar o conteúdo entregue, inclusive materiais produzidos com apoio de inteligência artificial. Cada integrante deverá conseguir explicar as decisões, evidências e critérios registrados.
